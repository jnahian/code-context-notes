# Changelog - Version 0.4.0

## [0.4.0] - 2026-07-17

v0.4 ships **`@jnahian/code-notes-mcp`** — a standalone MCP server giving any MCP-capable agent (Claude Code, Cursor) read/write access to workspace notes. Extension internals extracted into a shared **`@jnahian/code-notes-core`** package; behavior unchanged.

### Added
- **`@jnahian/code-notes-mcp` — standalone MCP server**
  - **Read tools:** `search_notes`, `get_notes_for_file`, `get_notes_for_changes` (pre-edit context loading), `list_instructions`, `get_handoffs`, `get_note`
  - **Write tools:** `create_note`, `edit_note`, `delete_note`, `add_handoff`, `add_decision` — write mode requires `--agent <name>`
  - **Resources:** `code-notes://digest`, `code-notes://index`, `code-notes://file/{path}`
  - **Per-note advisory file locks** (`.code-notes/.locks`) serialize concurrent writes
  - **Workspace-wide loader** scans all notes and populates `INDEX.json.errors[]` for unparseable files
  - **Directory-scope resolution** surfaces parent-folder notes for any file
  - **In-band JSON error convention** for all tool failures (`invalid_arguments`, `lock_timeout` retryable, `path_escapes_workspace`, etc.)

### Changed
- **Repo now uses npm workspaces** — the extension lives at `packages/extension/`
- **New shared package `@jnahian/code-notes-core`** — extension internals extracted, behavior unchanged

### Fixed
- **Sidebar now shows notes created by agents** — the file watcher's cache clear missed the workspace-wide caches, so externally-written notes stayed hidden until your next edit

### Settings
- None new on the extension side

### Compatibility
- Extension behavior unchanged; existing workspaces work without modification
- MCP server reads/writes the same `.code-notes/` directory the extension uses

### Testing
- 373 tests across packages: core 106, MCP server 72 (including cross-process extension-vs-MCP race, lock-contention, and stale-cache regression tests), extension 19 unit + 176 integration

### Technical
- npm workspaces monorepo: `packages/extension`, `packages/code-notes-core`, `packages/code-notes-mcp`
- MCP server built on `@modelcontextprotocol/sdk` (stdio transport); all logging on stderr, stdout reserved for JSON-RPC
- Advisory lock files (`.code-notes/.locks/<id>.lock`, exclusive create, 500ms retry, stale >60s broken) guard note writes in both extension and server; writers re-read inside the lock so a concurrent edit is never overwritten
- `--storage-dir` flag matches the extension's `codeContextNotes.storageDirectory` when it's been customized

### Coming Next
- v0.5 ships the trust model (`audit` / `queue` / `direct` modes) and the agent activity sidebar
