# Changelog - Version 0.3.0

## [0.3.0] - 2026-07-18

### Added
- **Structured Note Schema for Agent Integration**
  - Optional `type` (`context` default, `instruction`, `warning`, `decision`, `todo`, `handoff`, `rationale`), `priority` (`low`/`normal`/`high`/`critical`), `scope` (`line`/`function`/`class`/`file`/`directory`), `tags`, `authorType` (`human`/`agent`), `expiresAt` (ISO 8601), and `references` (PR/issue/commit/test/url) on every note
  - All fields optional — legacy v0.2.x notes load with sensible defaults, no migration required
  - New **`Set Note Type / Tags / Priority…`** command — Quick-Pick metadata editor for any note
- **Auto-Generated Workspace Exports for Coding Agents**
  - **`.code-notes/INDEX.json`** — machine-readable index with `byFile`/`byType`/`byTag` lookups and deterministic output, designed for MCP server consumption (v0.4+)
  - **`.code-notes/AGENTS.md`** — human-readable digest hoisting critical instructions/warnings, open handoffs, and decisions for coding agents (Claude Code, Cursor, etc.)
  - Debounced (200ms) atomic writes on every note change, with **`Regenerate Exports`** command for manual recovery
  - **`Link Notes Digest to AGENTS.md / CLAUDE.md`** command — opt-in, writes a marker-delimited managed block (with an `@`-import for Claude Code) into your root `AGENTS.md`/`CLAUDE.md` so agents discover the digest; idempotent, never touches content outside its markers
- **Sidebar Enhancements**
  - Note type shown as `· {type}` description suffix; high/critical priority as a tooltip badge
  - New title-bar actions: **Filter Notes by Type…** (multi-select) and **Toggle Expired Notes**

### Changed
- Sidebar toolbar gains filter and expired-notes toggles
- Fully backwards-compatible with v0.2.x — legacy notes load with defaults applied in memory; on-disk file stays byte-identical until the next edit

### Fixed
- CodeLens previews of multiline notes merged all lines together; now show only the first line with stray heading markers stripped
- Sidebar notes could render out of line-number order; previews now strip image markdown cleanly (`![alt](url)` no longer leaves a stray `!`)
- Comment labels always claimed "Last updated"; fresh notes now correctly show "Created"
- Edit-mode lookups (`getCurrentlyEditingComment`) used the wrong map key and never found the editing comment
- Soft-deleted notes disappeared from the cache entirely, breaking "already deleted" detection and metadata guards; they are also no longer retrievable via by-id lookup
- Stale compiled artifacts in `out/` ran phantom test suites; the test pipeline now cleans `out/` before compiling

### Testing
- 65 unit tests covering schema defaults, storage round-trip, export generator determinism and section hoisting, debounced atomic writer (coalescing + onError fail-safe), AGENTS.md managed-block linking (insert/append/replace/idempotency), and lazy-migration at the NoteManager boundary

### Technical
- New modules: `noteDefaults.ts` (defaults + expiry helper), `exportGenerator.ts` (pure index/digest builders), `exportWriter.ts` (debounced atomic writer with injectable config), `agentsLink.ts` (idempotent managed-block upsert)
- `NoteManager` wraps all storage reads with `applyDefaults` — single boundary for lazy migration of v0.2.x notes
- Storage parser/writer in `storageManager.ts` extends the existing bold-label markdown format with optional fields; values equal to default are omitted and unknown fields ignored gracefully
- New commands: `regenerateExports`, `setNoteMetadata`, `filterByType`, `toggleExpired`, `linkExports`
- New settings: `codeContextNotes.exports.enabled`, `.indexJson`, `.agentsMarkdown` (all default `true`)
